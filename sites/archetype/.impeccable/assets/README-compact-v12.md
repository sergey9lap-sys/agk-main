# Компактные арочные рамки v12

Встроенный ImageGen, transparent_background=true, три отдельные генерации. Каждый PNG и полный промпт сохранены рядом; публичные WebP лежат в ../../img/. Текст остаётся HTML. Скрипт обработки: scripts/archetype-media.mjs (прозрачные поля, ширина700, WebP quality88/alpha100).

- wide-arch-v12.png / wide-arch-v12.prompt.txt — широкие сравнения «Как привыкли / Как работаем мы».
- program-arch-v12.png / program-arch-v12.prompt.txt — карточки программы, без принудительной высоты изображения.
