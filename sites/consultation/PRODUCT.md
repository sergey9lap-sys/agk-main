## Users

Эксперты и онлайн-школы, которым нужна диагностика продуктовой линейки.

Новая страница AGK `/consultation` (нижний регистр; канонический directory index `/consultation/`). RU — agk-edu.ru, COM — agkedu.com. Пользователь заранее распространил адрес, менять slug нельзя.

Источник — актуальный `Диагностика_линейки_код_для_T123.txt`. Старый HTML сохранён вне проекта, не считается актуальным по приложенной инструкции. Текст, два встроенных изображения, состав и поля формы сохраняются. Сине-золотой мир AGK — прямое указание пользователя; Tilda-инструкция является описанием исходника, не требованием менять установленный стек.

Главная задача посетителя: понять бесплатную 30-минутную Zoom-диагностику, аудиторию, результат и оставить заявку. Пользователь передал GetCourse-виджет 1665870; он заменяет временную форму в обеих сборках RU/COM. Полями, согласием, отправкой и перенаправлением управляет GetCourse. Не отправлять тестовые заявки без отдельного разрешения и не использовать старые вебинарные виджеты. Ссылка на политику взята из текущих страниц AGK.

## Соответствие блоков

Уточнение пользователя: один экран, не многосекционный лендинг. Цветовой референс найден в `clients-funnels-webinar-2026/src/styles.css`: синий #0A2342, глубинный #06162C, золото #F5CF5C, бумага #F4F1EA. Текущий mkclients уже имеет другую редакцию; не брать прежний серо-фиолетовый #1B2234 за утверждённый AGK blue.

- Бесплатная диагностика, Zoom, 30 минут → исходная строка формата над H1.
- Заголовок и 30 минут разбора → левая колонка, на mobile перед формой.
- «Для кого», оба пункта → исходная группа после формы на mobile.
- «Что получите», оба пункта → исходная соседняя группа, без сокращения.
- Фото и подпись Александры, три числа → авторская группа; не скрывать числа на ноутбуке.
- Временные поля и отключённая кнопка → предоставленный виджет GetCourse справа, на mobile сразу после заголовка. Состав полей задаётся внешним виджетом.
- Условия, политика, ограничение мест → сохранены. Статус загрузки исчезает после появления iframe; при ошибке предлагает обновить страницу.

Цифры и обещания предоставлены в исходнике, независимо не проверены; новые факты не добавлять.
