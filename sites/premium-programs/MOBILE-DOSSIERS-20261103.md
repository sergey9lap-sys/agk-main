# Мобильные досье — исправление видимости

На мобильной ширине исходный `styles.css` устанавливал `.dossier-card { opacity:0 }`. После прежней замены интерактивных планшетов готовыми изображениями это правило осталось. GSAP `from({opacity:0})` считывал такое же нулевое конечное состояние; reduced-motion пропускал эффект и также сохранял CSS-ноль. Все шесть карточек занимали высоту, но были невидимыми — получался длинный бордовый пустой блок.

Исправлено конечное CSS-состояние на `opacity:1`. Высота, порядок, шесть изображений, скрытые доступные тексты, анимация и соседние блоки сохранены. Регистрационные виджеты и тарифы не менялись.

Пересобран Next static export, затем обе сборки AGK. Проверка проходит по каждой из шести карточек, а не только по первому экрану: 320/390/430/768/1440px × обычное движение/reduced-motion, дополнительно JavaScript выключен на320/390px. Проверяются непрозрачность после появления, загруженное изображение, размеры, отсутствие горизонтального переполнения и ошибок JavaScript. Материалы: `output/premium-mobile-dossiers-20261103/`.

При следующих правках содержательные карточки должны быть видимы в базовом CSS. Скрывать их может только временный эффект с гарантированным конечным состоянием; отказ анимации, reduced-motion и отсутствие JavaScript не должны оставлять пустые места.
