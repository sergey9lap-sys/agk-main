# AGK Main

Единый репозиторий сайтов Академии. Одна ветка `main`, общие исходники, две независимые сборки.

## Структура

```text
sites/clients/       сайт вебинара → /clients/
sites.json          список сайтов и настройки виджетов RU/COM
scripts/build.mjs   сборка всех сайтов для выбранной аудитории
dist/com/           результат для Vercel (не в Git)
dist/ru/            результат для Beget (не в Git)
```

Главной страницы сейчас нет; `/clients/` работает независимо. На `/` до появления главной возможна 404 — это ожидаемо.

## Vercel — COM

Импортировать **sergey9lap-sys/agk-main**, ветка **main**.

| Настройка | Значение |
|---|---|
| Project Name | agk-main |
| Root Directory | оставить пустым, корень репозитория |
| Framework Preset | Other |
| Build Command | npm run build:com |
| Output Directory | dist/com |
| Install Command | автоматически по pnpm-lock.yaml |

Команды и output уже заданы в vercel.json. Домен COM подключается ко всему проекту. Вебинар: `https://agkedu.com/clients/`, подарок: `https://agkedu.com/thanks/`. Сайты при добавлении новых папок публикуются одной сборкой — Root Directory менять не нужно.

## Beget — RU

Установить зависимости и выполнить `npm run build:ru`. Загрузить **содержимое** `dist/ru/` в корень сайта. Нужен обычный статический хостинг с directory index (index.html). Вебинар: `https://ВАШ-RU-ДОМЕН/clients/`, благодарность: `https://ВАШ-RU-ДОМЕН/spasibo/`. RU-домен не подтверждён. Не загружать COM-сборку на RU.

## GetCourse

| Сборка | Виджет | Полный URL после успешной регистрации |
|---|---|---|
| COM | 1656005 | https://agkedu.com/thanks/ |
| RU | 1655985 | https://ВАШ-RU-ДОМЕН/spasibo/ |

Перенаправление всей страницы после успешной отправки настраивается в GetCourse. data-success-path только документирует ожидаемый адрес, не имитирует успех и не отправляет заявки. Проверить регистрацию после настройки форм с согласованными данными. Чаты подарка подключены; отдельные Telegram/Макс/VK службы заботы ожидаются от клиента.

## Новый сайт

Добавить `sites/<slug>/` и запись в sites.json. Не копировать папки RU/COM: различия указываются в editions. Сборщик изолирует ресурсы по `/<slug>/`, проверяет конфликты адресов. Текущий шаблон сборки рассчитан на Vite-лендинги с public и src/thank-you.html; для другого стека адаптировать сборку явно.

## Проверка

`npm run build:com`, `npm run build:ru`, `npm test`.
Прежние репозитории оставлены нетронутыми; дальнейшая работа АГК ведётся в этом репозитории.
