## Пересборка

В каждом Next-проекте: `pnpm install --frozen-lockfile --ignore-workspace`, затем `node node_modules/next/dist/bin/next build`. В Менторинге: `node build.mjs`. Затем из корня `node scripts/package-products-export.mjs`, обычные `build:com`/`build:ru`. На Timeweb публикация стандартным `/usr/local/sbin/agk-main-update`.
