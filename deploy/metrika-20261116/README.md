## Цели в кабинете Метрики

Создать цели типа «Целевое событие» с этими точными идентификаторами:

| Модератор | Метод Фест | Значение |
|---|---|---|
| moderator_tariff_click | methodfest_tariff_click | Нажатие на конкретный тариф, параметр tariff |
| moderator_care_telegram | methodfest_care_telegram | Переход к службе заботы в Telegram |
| moderator_care_max | methodfest_care_max | Переход к службе заботы в MAX |
| moderator_thanks_view | methodfest_thanks_view | Просмотр страницы Спасибо |

Клик по тарифу НЕ означает отправленную заявку. Просмотр Спасибо НЕ подтверждает оплату.
Для регистрации и оплаты нужны подтверждённые события GetCourse/настроенный переход;
текущий сайт не имеет проверенного сигнала успешной оплаты. Чужие сообщения postMessage не считаются успехом.
Настройки целей в кабинете отдельно от установки кода; без доступа к кабинету их наличие не подтверждено.
Справка: https://yandex.ru/support/metrica/ru/objects/reachgoal

## Публикация

publish.sh копирует текущий выпуск сервера, добавляет один файл JS и тег в четыре HTML.
Проверяет хеши всех остальных файлов; исходная версия остаётся для отката.
Не запускать общий agk-main-update: старый основной исходник не содержит последних правок лендингов.
Слайдер из отдельного предпросмотра этим пакетом не публикуется.
Для последующих пересборок включать patch.py в финальный этап публикации актуальных экспортов.
