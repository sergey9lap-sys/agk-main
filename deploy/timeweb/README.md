## Пути сервера

- `/opt/agk-main/source` — checkout исходников.
- `/var/www/agk-main/releases/<commit>-ru` — готовые неизменяемые статические выпуски.
- `/var/www/agk-main/current` — атомарно переключаемая ссылка на рабочий выпуск.
- `/usr/local/sbin/agk-main-update` — обновление вручную из main, сборка только RU, проверка маршрутов, сохранение прежнего выпуска и откат при ошибке проверки.
- `/etc/nginx/sites-available/agk-main` — конфигурация домена.
- `/var/backups/agk-main` — исходная конфигурация Nginx и ссылка default.
- `/var/log/agk-build.log`, `/var/log/agk-release.log` — журналы первоначальной сборки и публикации.
- `/var/log/nginx/agk-main.access.log`, `agk-main.error.log` — журнал запросов сайта.

## Обновление

После согласованного коммита и push в main выполнить в root-консоли сервера:

```sh
/usr/local/sbin/agk-main-update
```

Сам push пока не запускает обновление Timeweb автоматически. COM продолжает свой обычный Vercel-deploy. Не возвращаться к загрузке Beget-архивов для RU.

Предыдущие каталоги выпуска не удаляются автоматически. Для ручного отката переключить current на проверенный каталог из releases; не удалять старый выпуск до проверки. Nginx не требует отдельного Node-процесса: он раздаёт готовую статическую RU-сборку.

## HTTPS и маршрутизация

Сертификат Let’s Encrypt для обоих имён; отдельное разрешение пользователя на принятие условий получено 03.11.2026. Аккаунт создан без передачи e-mail. Certbot timer выполняет продление; deploy-hook проверяет Nginx и перечитывает сертификат.

`agk-main-http.conf` — первичная конфигурация для HTTP/ACME. После выпуска сертификата `prepare-https-config.mjs` создаёт `agk-main-https.conf`; применять только при наличии сертификата. Включены HTTP→HTTPS и www→основной домен, gzip, часовой кеш медиа и no-cache для страниц. Исходные Apache `.htaccess` сохранены в сборке, но не исполняются Nginx: directory index и тематические ошибки заданы явно в конфигурации.

Все текущие вложенные адреса, формы GetCourse и страницы благодарности сохраняют RU-домен; настройка виджетов внутри GetCourse не менялась. Реальные регистрации и оплаты в ходе миграции не отправляются.
